# Final Project Starter

앞에서 배운 내용을 한 번에 새로 작성하지 않고, 제공된 골격에 핵심 Agent 로직을 채우는 방식으로 진행합니다.

## 구현 순서

1. `tools.py` — 제공된 Tool 확인
2. `state.py` — 상태 구조 확인
3. `agents.py` — Product / Policy 전문 Agent 완성
4. `supervisor.py` — Agent-as-Tool과 Supervisor 완성
5. `main.py` — 복합 질문 실행

실습 목표는 **Tool → 전문 Agent → Supervisor → 최종 응답** 흐름을 직접 연결하는 것입니다.
