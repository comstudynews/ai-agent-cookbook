# 01_starter

수강생이 수업 중 직접 완성하는 코드입니다.

원칙은 **전체 코드를 처음부터 타이핑하지 않고 Agent 설계에 중요한 부분만 직접 작성**하는 것입니다.

- TODO가 있는 부분만 작성합니다.
- 막힌 상태로 10분 이상 머물지 않습니다.
- 교수자가 Checkpoint 이동을 안내하면 `03_checkpoint/`에서 다시 합류합니다.
- 완성 코드를 먼저 복사하기보다 실행 흐름을 이해하는 데 초점을 둡니다.

현재 Starter는 수업에서 핵심 전환점이 되는 Step을 우선 제공합니다. Cookbook의 전체 Step은 루트 소스와 함께 순차적으로 확장합니다.
