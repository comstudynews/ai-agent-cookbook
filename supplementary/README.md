# 보충 실습

[Notion 교재](https://app.notion.com/p/3df91bd5a9ac8167928af84bceafc375?pvs=204)의 동일한 단계를 실습합니다.

**실습 파일**
- [extra_typeddict.py](complete/extra_typeddict.py) — `python extra_typeddict.py`
- [extra_typeddict_mypy.py](complete/extra_typeddict_mypy.py) — `python extra_typeddict_mypy.py`
- [extra_messages.py](complete/extra_messages.py) — `python extra_messages.py`
- [extra_message_graph.py](complete/extra_message_graph.py) — `python extra_message_graph.py`
- [extra_messages_state.py](complete/extra_messages_state.py) — `python extra_messages_state.py`
- [extra_checkpointer.py](complete/extra_checkpointer.py) — `python extra_checkpointer.py`
- [extra_agent_integration.py](complete/extra_agent_integration.py) — `python extra_agent_integration.py`

**두 가지 사용 방식**
- `practice/`: 교재와 같은 최신 코드로 시작하여 TODO 내용에 맞게 질문·조건·분기를 바꾸어 보는 실험형 실습(실행 가능)
- `complete/`: Notion 교재에 수록된 완료 코드

저장소 루트에도 동일 완료 코드가 있으므로 Notion의 실행 명령은 루트에서 그대로 사용할 수 있습니다. `complete/`에서 실행할 경우 먼저 `cd supplementary/complete`로 이동하세요. 패키지는 루트의 `requirements.txt`로 설치합니다.
